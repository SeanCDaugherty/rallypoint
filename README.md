# Rally Point

Civilian **check point** for combat veterans. Offline-first.

## Features
- Real interactive map (OpenStreetMap) — search, tap to pin, named AOs
- Paste a **Google Maps** link to drop a pin
- Open any pin in Google Maps
- Ironic **postcards** from AOs (“Greetings from sunny Al Asad…”)
- Prayers, walk-through, profile photo, instructions
- Breathe, claims, rating estimator, crisis (988)

Open `index.html` or enable GitHub Pages on `main` / root.

Not treatment. Not a VA decision.
